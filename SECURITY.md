# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or a configuration change that could compromise system integrity, please report it via GitHub Private Vulnerability Reporting or open an advisory report.

Please include:
- Windows version and build number
- Architecture (x86 vs x64)
- Exact steps to reproduce the issue
- Relevant logs or stack traces

We aim to acknowledge and address all reports within 48 hours.
